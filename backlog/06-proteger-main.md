title: Protéger la branche main
labels: git
---

Ce matin, tout le monde a poussé directement sur `main`.

**Critères d'acceptation**

- [ ] un ruleset protège la branche par défaut : pull request obligatoire avec 1 approbation, force push et suppression interdits
- [ ] un `git push` direct sur `main` est refusé (capture d'écran en commentaire de ce ticket)
