---
title: Impossible de lancer le projet en suivant le README
labels: env
---

Le README demande d'installer PostgreSQL à la main, de créer la base, puis `npm start`. Chez la moitié de l'équipe ça ne marche pas, et personne ne sait quelle version de quoi installer.

**Critères d'acceptation**

- [ ] Depuis un clone tout neuf, l'application démarre avec 3 commandes documentées dans le README
- [ ] Le README liste les prérequis (avec versions) et contient une section « Dépannage »
- [ ] Testé par **chaque** membre de l'équipe sur sa machine
