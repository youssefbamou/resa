---
title: Partager la configuration de l'éditeur
labels: env
---

Tabulations chez l'un, espaces chez l'autre, fins de ligne Windows chez le troisième : chaque commit modifie des lignes qui n'ont pas changé.

**Critères d'acceptation**

- [ ] `.editorconfig` (indentation, fins de ligne LF, encodage UTF-8)
- [ ] `.gitattributes` (`* text=auto eol=lf`)
- [ ] `.vscode/extensions.json` recommande ESLint, Prettier, EditorConfig, Docker et SonarQube for IDE
